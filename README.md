## 📚 项目简介

AD886 是一个聚合和优化多源广告拦截规则的工具，旨在为 **广告拦截器** 提供高效、可靠的过滤规则。  
支持以下工具：

- **AdGuard**
- **uBlock Origin**
- **其他兼容规则的广告拦截工具**

项目会每日自动更新，确保规则库的最新性和有效性。

## 🔧 使用指南

1. **选择规则库链接**  
   点击上表中的订阅链接，复制链接地址。

2. **添加到广告拦截工具**  
   在 AdGuard 或 uBlock Origin 的设置中添加订阅链接。

3. **保存并启用**  
   确保规则生效，随时享受更清爽的浏览体验！
